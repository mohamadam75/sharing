# My Flash — فلش اینترنتی اشتراکی

فضای اشتراک فایل فارسی با ثبت‌نام نام کاربری/رمز عبور، آپلود، نمایش و دانلود. همه کاربران واردشده فایل‌ها را می‌بینند؛ فقط مالک هر فایل می‌تواند آن را حذف کند.

## امکانات
- ثبت‌نام و ورود بدون ایمیل یا شماره موبایل
- آپلود چند فایل تا ۵۰ مگابایت برای هر فایل
- نمایش عکس، PDF، ویدئو و فایل‌های قابل پخش مرورگر
- دانلود، جستجو و حذف فایل توسط بارگذار
- نمایش حجم، نام بارگذار و تاریخ آپلود
- رابط فارسی و واکنش‌گرا
- Cloudflare Pages Functions برای API، Cloudflare D1 برای کاربران/نشست‌ها/فراداده و Supabase Storage برای محتوای فایل‌ها

## تنظیمات Cloudflare Pages
Build output directory برابر `public` و Build command خالی باشد. در بخش **Settings → Functions → Bindings** اتصال D1 با نام `DB` به دیتابیس `my-flash-db` وصل باشد (Production و Preview).

در **Settings → Variables and Secrets** این مقادیر را در محیط Production تنظیم کن:
- `SUPABASE_URL` = آدرس پروژه Supabase
- `SUPABASE_BUCKET` = `my-flash-files`
- `SUPABASE_SERVICE_ROLE_KEY` = کلید محرمانه Service Role پروژه My Flash، با نوع **Secret** (نه Plain text)

همین سه مقدار را برای Preview هم در صورت نیاز تنظیم کن. کلید Service Role را هرگز در GitHub، کد مرورگر یا پیام عمومی قرار نده. باکت Supabase باید Private بماند؛ API سمت سرور با این کلید به Storage دسترسی می‌گیرد و قبل از هر عملیات، نشست و مالکیت را در D1 بررسی می‌کند.

## دیتابیس D1
ساختار جداول در `schema.sql` است. دیتابیس باید شامل جداول `users`، `sessions` و `files` باشد. پروژه Supabase فقط برای ذخیره فایل استفاده می‌شود؛ اطلاعات حساب‌ها در D1 باقی می‌ماند.

## استفاده
لینک سایت را به افراد بده. هر نفر نام کاربری و رمز می‌سازد. پس از ورود همه فایل‌های اشتراکی را می‌بینند؛ حذف فقط برای صاحب فایل فعال است.

## محدودیت‌ها
- حداکثر حجم هر فایل: ۵۰ مگابایت
- فهرست ۵۰۰ فایل آخر را نشان می‌دهد.
- فایل‌ها در فضای مشترک هستند و همه کاربران واردشده به آن‌ها دسترسی دارند.
- محدودیت سهمیه مصرف و rate limit تلاش‌های ورود در این نسخه وجود ندارد.

## امنیت
رمز عبور با PBKDF2-HMAC-SHA256 و ۱۵۰٬۰۰۰ دور مشتق‌سازی می‌شود. نشست‌ها با توکن تصادفی در کوکی HttpOnly/Secure نگهداری و فقط hash آن‌ها در D1 ذخیره می‌شود. درخواست‌های فایل از Pages Functions عبور می‌کنند؛ کلید privileged سمت سرور نگهداری می‌شود و هرگز به مرورگر ارسال نمی‌شود.
