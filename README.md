# My Flash — فلش اینترنتی اشتراکی

یک فضای انتقال فایل فارسی با ثبت‌نام ساده (نام کاربری و رمز عبور)، آپلود، نمایش و دانلود. همه کاربران واردشده فایل‌های فضای اشتراکی را می‌بینند؛ حذف هر فایل فقط برای صاحب آن فعال است.

## امکانات نسخه اول
- ثبت‌نام و ورود بدون ایمیل یا شماره موبایل
- آپلود چند فایل و نوار پیشرفت
- پشتیبانی از هر نوع فایل تا ۵۰ مگابایت برای هر فایل
- نمایش عکس، PDF، ویدئو و فایل‌های قابل پخش مرورگر در تب جدید (بسته به پشتیبانی مرورگر)
- دانلود، جستجو و حذف فایل توسط بارگذار
- نمایش حجم، نام بارگذار و تاریخ آپلود
- رابط فارسی و واکنش‌گرا
- نگهداری فایل‌ها در Cloudflare R2 و اطلاعات کاربران/فایل‌ها در Cloudflare D1

## راه‌اندازی (یک‌بار برای همیشه)
**نکته:** GitHub فقط کد را نگهداری می‌کند. برای اجرای ورود کاربران و ذخیره واقعی فایل‌ها باید پروژه را روی Cloudflare Pages منتشر کنی؛ GitHub Pages برای این نسخه کافی نیست.

1. وارد داشبورد Cloudflare شو و از بخش **Workers & Pages** یک Pages project بساز و مخزن GitHub با نام `mohamadam75/sharing` را وصل کن.
2. تنظیمات Build:
   - Framework preset: **None**
   - Build command: خالی
   - Build output directory: `public`
3. در بخش **D1 SQL Database** یک دیتابیس با نام دلخواه مثل `my-flash-db` بساز.
4. دیتابیس را باز کن، وارد **Console** شو، محتوای فایل `schema.sql` را کپی و اجرا کن.
5. در **R2 Object Storage** یک bucket با نام دلخواه مثل `my-flash-files` بساز.
6. در تنظیمات Pages project، بخش **Settings → Functions → Bindings** این دو اتصال را اضافه کن:
   - D1 database: متغیر `DB` ← دیتابیسی که ساختی
   - R2 bucket: متغیر `BUCKET` ← باکتی که ساختی
   این اتصال‌ها را برای Production و در صورت نیاز Preview هم تنظیم کن.
7. یک بار دیگر Deploy کن و آدرس Pages را باز کن. اولین کاربر می‌تواند حساب بسازد.

## استفاده
- لینک سایت را برای افراد موردنظر بفرست.
- هر نفر با یک نام کاربری و رمز عبور حساب می‌سازد.
- پس از ورود، فایل‌های فضای مشترک را می‌بیند و می‌تواند فایل جدید آپلود یا دانلود کند.
- فقط صاحب هر فایل می‌تواند آن را حذف کند.

## محدودیت‌های فعلی
- حداکثر حجم هر فایل: ۵۰ مگابایت
- فهرست حداکثر ۵۰۰ فایل آخر را نمایش می‌دهد.
- فایل‌ها در فضای مشترک هستند و همه کاربران واردشده به آن‌ها دسترسی دارند؛ این نسخه پوشه خصوصی جداگانه برای هر کاربر ندارد.
- لینک مستقیم فایل بدون ورود کار نمی‌کند.
- نسخه فعلی محدودیت سهمیه مصرف برای هر حساب و محدودسازی تلاش‌های ناموفق ورود ندارد؛ برای استفاده عمومی پرترافیک باید اضافه شوند.

## امنیت
رمز عبور با PBKDF2-HMAC-SHA256 و ۱۵۰٬۰۰۰ دور مشتق‌سازی می‌شود. نشست‌ها به شکل توکن تصادفی در کوکی HttpOnly/Secure نگهداری و در دیتابیس فقط به‌صورت SHA-256 ذخیره می‌شوند. ارتباط API فقط برای کاربر واردشده مجاز است.
